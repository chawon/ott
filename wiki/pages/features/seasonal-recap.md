## 현재 상태

| 항목 | 상태 |
|---|---|
| 리캡 키 | `2026-H1` |
| 집계 기간 | KST `2026-01-01`~`2026-06-30` |
| 노출 기간 | KST `2026-07-01`~`2026-07-31` |
| 종료 시각 | KST `2026-08-01 00:00` |
| 현재 사용자 노출 | 종료 |

2026년 상반기 리캡은 영상·책 기록을 포스터, 대표 활동 지표와 SNS 공유 카드로 보여준 7월 한정 기능이다. 추천이나 성과 평가는 포함하지 않았다. 리캡이 종료돼도 원본 기록과 일반 개인 리포트는 유지된다.

## 계약과 노출 경계

- 개인 리포트 API `GET /api/nalytic/me/report`의 `seasonalRecap`은 nullable이다.
- API와 웹은 KST 기준 `[2026-07-01, 2026-08-01)`에만 `2026-H1` 리캡을 만든다.
- 웹은 서버 응답, 리포트 렌더, IndexedDB fallback과 상단 노티에 같은 종료 게이트를 적용한다.
- 대표 값은 전체 기록 수, 콘텐츠 유형·장소·상황, 완료율, 메모 작성률과 최대 6개 포스터다.
- 캠페인 이벤트는 노티 노출·클릭·닫기, 리캡 노출과 공유를 구분한다.

상세 API 필드, 코드 위치와 재사용 원칙은 `docs/2026-h1-recap.md`를 기준으로 한다.

## 플랫폼 경계

- Web/PWA/Android TWA는 웹 게이트에 따라 리캡을 내렸다.
- 온라인 iOS 클라이언트는 API의 `seasonalRecap=null`을 받는다.
- 이번 배포에서는 iOS 네이티브 소스와 App Store 바이너리를 변경하지 않았다. 네이티브 오프라인 로컬 fallback 종료는 별도 후속 범위다.
