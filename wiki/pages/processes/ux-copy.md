# UX 문구

[DESIGN.md의 Voice & Tone](../../../DESIGN.md#10-voice--tone)을 제품 공통 기준으로 사용한다. 기록과 다시 보기, 기기 연결을 일상적인 말로 안내한다. 한국어는 편한 해요체, 영어는 짧은 문장과 sentence case를 사용한다.

| 상황 | 문구 기준 |
| --- | --- |
| 기록 | 콘텐츠는 작품, 감상 이력은 기록 또는 타임라인으로 부른다. 기록 저장은 `기록 남기기`처럼 실제 행동을 쓴다. |
| 진행과 완료 | 저장 중, 이 기기에 저장됨, 동기화 완료를 실제 상태에 맞춰 안내한다. |
| 오류와 빈 상태 | 현재 상태를 짧게 설명하고 바로 가능한 다음 행동을 안내한다. |
| 기기 연결 | 기록 연결 코드와 복구 카드를 구분한다. 로컬 초기화와 서버 데이터 전체 삭제는 대상과 결과를 확인할 수 있게 쓴다. |

문구를 변경할 때는 [변경안](../../../docs/changes/README.md)에서 한국어·영어와 적용할 앱을 확인한다. Web의 사용자 문구는 [ko.json](../../../apps/web/messages/ko.json)과 [en.json](../../../apps/web/messages/en.json)에서 확인한다. 다른 앱은 [플랫폼 현황](../../../docs/platforms.md)의 소스를 기준으로 한다. 초기 검토 이력은 [문구 아카이브](../../../docs/archive/reviews/ux-copy-consistency-playbook-2026-02-10.md)에 있다.
