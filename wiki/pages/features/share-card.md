# 공유 카드 (Share Card)

> 개별 기록과 이용 리포트를 SNS 친화적인 이미지 카드로 생성해 공유하는 기능

## 관련 페이지
- [[book-log]]
- [[analytics]]

- [[seasonal-recap]]

---

## 목표

- 기록 저장 직후 바텀시트로 공유 유도
- SNS 친화적 이미지 카드 생성 (Story 1080×1920 기준)
- 지난주 기록의 대표 작품을 포스터 모자이크로 회고
- MVP: 템플릿 1(한 줄 감상 카드)만 제공

---

## 주요 결정 사항

| 항목 | 결정 |
|---|---|
| 노출 타이밍 | 기록 저장 후 "공유 카드 만들기" 체크 시만 표시 |
| 평점 표기 | 문구 + 1자리 점수(예: 5.0), 토글로 포함/제외 |
| 메모 | 토글로 포함/제외, 줄바꿈 2줄까지 |
| 워터마크 | 기본은 `ottline.app` |
| 프로필 서명 | 프로필 완성 시 선택 옵션으로 `아바타 + 닉네임 · by ottline.app` 표시 |
| 출력 사이즈 | Story 1080×1920, Feed 1080×1350 |
| 포스터 | 시즌 포스터 우선, 없으면 기본 포스터 |
| 주간 리포트 후보 | KST 직전 주 작품을 중복 제거해 최대 6개 선정 |
| 주간 리포트 정렬 | 포스터 유무, 평점 유무·점수, 기록 수, 최근 기록 순 |
| 이미지 없음 | 작품 후보는 유지하고 모자이크 칸에 제목 표시 |

## UX 플로우

1. QuickLog 저장 성공 → 체크된 경우 바텀시트 오픈
2. 바텀시트: 카드 미리보기 + 토글(평점/메모/프로필 서명) + 비율 선택 + 버튼(이미지 저장, 공유하기)
3. 공유 방식
   - 모바일: Web Share API (이미지 파일)
   - 데스크탑: 이미지 다운로드

---

## 템플릿 1 구성

- 상단 70%: 포스터 영역
- 하단 30%: 텍스트 패널(제목/메모/메타 칩)
- 메타 칩: 상태/평점/날짜
- 좌하단: 워터마크
- 프로필 서명 옵션 ON: 좌하단에 아바타, 닉네임, `by ottline.app`

**규칙:**
- 메모: 2줄까지만, 나머지 `…` 처리
- 제목: `:` 뒤에서 줄바꿈
- 날짜: `YYYY.MM.DD` 포맷

## 기술 선택

**Satori (vercel/og) 채택** — 서버 사이드 이미지 렌더링
- 장점: 모바일/데스크탑 동일 품질, CORS 이슈 적음
- 단점: CSS 제한, 폰트 파일 필요

서버 이미지 렌더 API: `/[locale]/og/share-card`

## 주간 이용 리포트 카드

- `GET /api/nalytic/me/report`의 `previousWeekPosters`를 주간 공유 payload의 `posterItems`로 전달한다.
- 서버 응답을 쓸 수 없는 로컬 우선 상태에서도 IndexedDB 기록으로 같은 후보를 계산한다.
- 후보 수 1~6개에 맞춰 상단 포스터 영역을 채우므로, 기록이 있는데 빈 포스터 영역만 남지 않는다.
- 시즌 기록은 시즌 포스터를 우선하고, 포스터 URL을 불러올 수 없는 작품은 제목 fallback으로 구분한다.
- `2026-09-21` PR `#108`, API/Web SHA `01ef6b9`로 운영 반영했다.
